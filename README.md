# Sudden Strike Rebuild releases

This public repository distributes existing Windows development preview binaries and integrity metadata only. Game source code remains in its original repository.

The sourceCommit in each release manifest identifies the game source used to build that artifact; the release tag here points to this delivery repository. They are different histories.

These are unsigned Windows x64 development previews, not a complete reconstruction of the original game. Fully extract the ZIP before running SuddenStrikeRebuild.exe. macOS, native mouse, audio-device and actual-window visual acceptance are not claimed for the current public package.

The landing page and release notes describe the tested scope. A hosting migration does not create a new game version.
